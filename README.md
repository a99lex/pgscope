# PgScope

PostgreSQL Performance Advisor.

## Features

- Multi-cluster PostgreSQL monitoring
- Dynamic cluster discovery
- Query history
- Explain plans
- Health reports
- Print / Save PDF
- Authentication with forced first-login password change
- Retention cleanup

## Components

- PgScope API
- PgScope Collector
- PostgreSQL storage database
- Kubernetes Secrets
- Kubernetes manifests / Helm
